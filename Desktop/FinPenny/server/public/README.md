# Admin Panel (admin.html)

Place your admin panel HTML file here. This is where `server.js` serves static files from `express.static(path.join(__dirname, 'public'))`.

To use the admin panel:
1. Copy your `admin.html` file to this directory
2. Rename it to `admin.html` (or `index.html` for root access)
3. Access it at: `http://localhost:8000/admin.html`

If you want to serve it at the root:
1. Rename it to `index.html`
2. Access it at: `http://localhost:8000/`
